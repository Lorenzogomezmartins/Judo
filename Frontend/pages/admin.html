Federación Metropolitana de Judo

Panel de Administración

Desde este panel podés administrar el contenido principal de la Federación Metropolitana de Judo.

Sección Ranking / Inscripciones
  1. Tocar el botón Importar desde Google Sheets.
  2. El sistema lee el excel de ranking.
  3. Solo importa judokas que tengan DNI y foto.
  4. Si el judoka no existe, lo crea automáticamente.
  5. Si el judoka ya existe y cambió algún dato, lo actualiza.
  6. No duplica personas porque usa el DNI como identificador.
Sección Clubes
  1. Tocar Agregar Club.
  2. Completar nombre, teléfono, dirección y sitio web.
  3. Subir logo si corresponde.
  4. Guardar para que el club aparezca en la página pública.
  5. Usar el botón de editar para modificar datos existentes.
  6. Usar eliminar solo si el club ya no debe mostrarse.
Sección Patrocinadores
  1. Tocar Agregar Patrocinador.
  2. Completar nombre, contacto y sitio web.
  3. Subir el logo del patrocinador.
  4. Guardar para mostrarlo en la página pública.
  5. Editar si cambia el logo, contacto o enlace.
  6. Eliminar si ya no corresponde mostrarlo.
Sección Profesores
  1. Tocar Agregar Profesor.
  2. Completar nombre, apellido, club y descripción.
  3. Subir foto si corresponde.
  4. Cargar capacitaciones una por línea.
  5. Respetar el formato: título, club, fecha y descripción.
  6. Guardar para que aparezca en la sección pública de profesores.
Sección Torneos
  1. Tocar Agregar Torneo.
  2. Completar nombre, fecha, dirección, categorías y reglas.
  3. Subir una foto principal del torneo.
  4. Agregar link de YouTube si hay transmisión en vivo o video publicado.
  5. Al guardar, el sistema crea el torneo en la Base de datos.
  6. También crea automáticamente la carpeta del torneo para subir el FTP (los resultados).
  7. También intenta crear el evento en Google Calendar.
  8. Si se elimina un torneo, también se elimina su carpeta de resultados.
  9. No editar el nombre para cambiar si ya hay resultados cargados.
Sección Galería
  1. Tocar Agregar Foto.
  2. Subir una imagen desde la computadora.
  3. El título es opcional y sirve para buscar fotos.
  4. La fecha también es opcional.
  5. Guardar para que la foto aparezca en la galería pública.
  6. Las fotos pueden recibir Me gusta.
  7. En el inicio se muestran las 5 fotos con más Me gusta.
  8. Usar editar para cambiar título, fecha o imagen.
  9. Usar eliminar si la foto ya no debe mostrarse.
